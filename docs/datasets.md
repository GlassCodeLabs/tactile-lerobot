# Public tactile datasets

This page lists public tactile datasets and how each one maps onto the layout in [SCHEMA.md](../SCHEMA.md). **Verdicts are against SCHEMA.md 0.4**, and change when the schema does.

Checked 8 November 2026, against SCHEMA.md 0.4.

Keys, shapes, dtypes and rates come from reading the dataset files. A sensor name or rate appears only where the dataset's own documentation states it; a dash means it is not stated. Licences are the dataset's own; the licence governs redistributing the data, not describing it. Datasets whose tactile files could not be read (archives too large to open, video-only tactile streams, data hosted off the Hub) are left out.

## Verdicts

- **clean**: the tactile arrays can be written as `observation.tactile.<id>` unchanged, with renaming and static metadata only.
- **with conversion**: values or layout must be transformed first (split, reshape, decode, build timestamps), but the schema can represent the result.
- **no**: the dataset lacks something the schema requires, usually element geometry in millimetres for `taxel_array` and `magnetic` sensors (`layout.positions_mm`, or a grid with its pitch), or a stated unit.

SCHEMA.md stores each channel in its declared unit: a physical unit, or, where the dataset says its values are uncalibrated, `counts` (raw integers from the analog-to-digital converter) or `a.u.` (values the vendor scaled without a physical calibration). A force-torque or taxel reading whose unit is not stated is "no", since neither can be declared for it. The writer declares each feature's channels, so a single channel or an optional derived stream with no stated unit can be left out instead (TouchScale's shear, Daimon's deformation), and an axis a dataset does not have is declared `unavailable` (FEEL's moments).

When the source does not state the sensor's `vendor` and `model`, whoever writes the dataset has to supply them. That does not change the verdict.

"Per-frame timestamps" means a recorded clock per sample. LeRobot's own `timestamp` column, which is `frame_index / fps`, does not count, and neither does a time column resampled onto an exact grid. A dataset that keeps such a clock in a main-table column of its own declares it as `info.clock_column`.
